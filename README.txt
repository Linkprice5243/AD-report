GitHub Pages 업로드 안내

1. GitHub에서 새 Public 또는 Private 저장소를 만듭니다. (GitHub Pages 공개 여부는 설정과 플랜에 따라 달라질 수 있습니다.)
2. 이 폴더 안의 index.html, data.js 파일을 저장소 최상위(root)에 업로드하고 Commit합니다.
3. Settings > Pages > Build and deployment > Deploy from a branch를 선택합니다.
4. Branch: main / Folder: /(root)를 선택하고 Save합니다.
5. Pages에 표시된 URL로 접속합니다.

주의: 이 사이트는 파일 내 광고 데이터가 포함된 정적 사이트입니다. 공개 Pages에 올리면 데이터가 공개될 수 있으므로 광고주 데이터의 공개 허용 여부를 먼저 확인하세요.
새 데이터로 갱신하려면 data.js를 다시 생성해 교체해야 합니다.
